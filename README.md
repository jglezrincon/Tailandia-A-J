# Viaje a Tailandia

App del viaje de Julia y Ana (1–15 de enero de 2027): ruta por el mar de Andamán, mapa, traslados, lo que queda por reservar, dónde dormir, consejos y maleta.

Es una sola página (`index.html`) publicada con GitHub Pages. Las listas que se marcan se guardan en el navegador de cada persona.
